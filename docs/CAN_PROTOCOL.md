# F103 与 H743 的 CAN 监测通信

当前两份工程分别使用 STM32F103C8T6、STM32H743IIT6。
H743 工程目录虽在本次请求中被称为 F407，实际 `.ioc` 和 HAL 都是 H743。
本协议只传监测数据与心跳，不包含电机启动、停止、调速或解除故障命令。

## 总线和连接

- 经典 CAN，500 kbit/s，11 位标准数据帧，DLC 固定 8，禁用 CAN FD 和 BRS。
- F103：PA12/CAN_TX、PA11/CAN_RX；CAN 时钟 36 MHz，
  Prescaler=8、BS1=5 TQ、BS2=3 TQ、SJW=1 TQ。
- H743：PB9/FDCAN1_TX、PB8/FDCAN1_RX；FDCAN 内核时钟 36 MHz，
  NominalPrescaler=8、TimeSeg1=5、TimeSeg2=3、SJW=1。
- 两块 MCU 各经 CAN 收发器连接，CANH 接 CANH、CANL 接 CANL，并连接信号参考地。
  总线两个末端各放置 120 Ω 终端电阻，检查板载终端以免重复并联。
  MCU 的 TX/RX 引脚不能当成 CANH/CANL 直接相连。

## 报文总览

| ID | 方向 | 周期 | 用途 |
|---|---|---|---|
| `0x101` | H743 → F103 | 500 ms | H743 心跳 |
| `0x201` | F103 → H743 | 200 ms | 温度、电流、采样峰值、保护状态 |
| `0x202` | F103 → H743 | 与 `0x201` 同批 | INA180 输出电压、占空比、通信状态 |

`0x201` 和 `0x202` 的周期上报同时承担 F103 心跳。
协议版本为 1；多字节整数统一小端，不直接发送浮点数或 C 结构体。
同一批 `0x201`、`0x202` 使用相同序号，序号从 0 到 255 循环。

## `0x101`：H743 心跳

| 字节 | 内容 |
|---|---|
| 0 | 协议版本，固定 `0x01` |
| 1 | 心跳序号 |
| 2～3 | 保留，固定 0 |
| 4～7 | H743 RTOS 运行秒数，`uint32_t`，在 RTOS tick 回绕后重新计数 |

F103 只接受正确版本、长度和保留字段的心跳。
1.5 秒内收到有效心跳才设置 `HOST_ONLINE`。超时只用于监测，不控制电机。

## `0x201`：测量值

| 字节 | 内容 |
|---|---|
| 0 高 4 位 | 协议版本，固定 1 |
| 0 低 4 位 | 电机保护状态 |
| 1 | 本批序号 |
| 2～3 | 温度，`int16_t`，单位 0.1 ℃；`0x8000` 表示无效 |
| 4～5 | 中位数电流，`uint16_t`，单位 0.1 mA；`0xFFFF` 表示无效 |
| 6～7 | 本批 15 点的最大电流，`uint16_t`，单位 0.1 mA；`0xFFFF` 表示无效 |

状态定义与 `MotorProtectionState` 对应：

| 值 | 名称 | 含义 |
|---|---|---|
| 0 | `WAIT_SENSORS` | 等待有效且满足启动条件的温度与电流 |
| 1 | `READY` | 本地保护允许输出；实际是否驱动还取决于占空比 |
| 2 | `OVERHEAT_LATCHED` | 过温停机锁定 |
| 3 | `SENSOR_FAULT_LATCHED` | 传感器/ADC 采样异常锁定 |
| 4 | `OVERCURRENT_LATCHED` | 过流停机锁定 |

中位数电流不是 PWM 电流的平均值或有效值；采样峰值也可能漏掉采样间隙内的尖峰。
当前硬件仍为 INA180A1、1 Ω，过流阈值仍为 160 mA，CAN 接入不改变保护参数。

## `0x202`：状态

| 字节 | 内容 |
|---|---|
| 0 | 协议版本，固定 `0x01` |
| 1 | 与同批 `0x201` 相同的序号 |
| 2～3 | PA3/INA180 输出电压，`uint16_t`，单位 mV；`0xFFFF` 表示无效 |
| 4 | 当前生效的 PWM 占空比，0～100%；保护锁定时为 0 |
| 5 | 请求的 PWM 占空比，0～100%；保护锁定时仍可能保留非零请求 |
| 6 bit 0 | `HOST_ONLINE`：F103 最近收到 H743 的有效心跳 |
| 6 bit 1 | `RX_DROPPED`：F103 曾有接收读取失败或软件队列溢出 |
| 6 bit 2 | `TX_FAILED`：F103 曾有发送入队失败/邮箱忙 |
| 6 bit 3～7 | 保留为 0 |
| 7 | 保留为 0 |

诊断标志反映本次启动以来发生过的事件，不会因下一帧成功而清除。
`TX_FAILED` 统计提交发送失败，HAL 返回成功只表示已进入硬件发送队列，
不代表对方已接收或物理总线已完成 ACK。

## 示例

序号 7，温度 25.0℃，中位数电流 30.0 mA，采样峰值 40.0 mA，
INA180 输出 600 mV，保护允许运行、请求和实际占空比均为 50%，心跳在线：

```text
0x201  DLC=8  11 07 FA 00 2C 01 90 01
0x202  DLC=8  01 07 58 02 32 32 01 00
```

## 接收、配对与离线

双方均在调度器运行后启用 CAN 接收通知；中断复制报文到 16 帧静态队列，
不在中断或通信任务中打印串口。通信任务每轮最多处理 16 帧，再延时 10 ms。
F103 温度/电流保护任务的优先级高于通信任务。

H743 验证标准帧、数据帧、经典 CAN、DLC、版本及字段范围。
只有序号相同且两帧接收时间距当前均小于 500 ms，才发布一份完整数据。
两帧可以以任意顺序到达；半组数据不会覆盖已发布的完整数据。
接收时间在中断中记录，排队延迟不会把旧报文当成刚收到的新数据。

连续 1.5 秒没有完整数据时，H743 标记 `OFFLINE`，保留最后一次值供检查，
同时显示数据年龄；首次收到数据前显示 `WAIT_DATA`。
`ONLINE` 表示通信近期有完整上报，不等于所有传感器正常；传感器有效性仍需看无效值和保护状态。
双方当前禁用自动重发，发送忙时放弃本次报文，下一周期发送最新值，不阻塞采样。
离线时检查接线、终端、收发器和错误状态；本次未新增 bus-off 自动恢复。

## 调试验证

1. 构建并烧录两端固件，连接经典 CAN 总线。
2. H743 串口应从 `WAIT_DATA` 变成 `ONLINE`，显示温度、电流、峰值、状态和占空比。
3. 用 CAN 分析仪核对三个 ID、报文长度、字节序及同批序号。
4. 断开 H743→F103 心跳，确认 F103 的 `HOST_ONLINE` 在 1.5 秒后变为 0。
5. 停止 F103 上报，确认 H743 在 1.5 秒后显示 `OFFLINE`，旧值带数据年龄。
6. 触发本地过温或过流，确认 PWM 归零、状态上报锁定；心跳恢复不能解除故障。

当前电机保留原有上电行为：本地传感器满足条件后输出默认 50% 占空比。
通信中断不会自动启停电机。固件编译和主机测试不能替代双板总线验证。
